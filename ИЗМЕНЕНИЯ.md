# StudHub V1.8.9 — исправление аватарок и ограничений

## Что изменено
- Аватар загружается в Supabase Storage (`avatars`) в папку UUID пользователя.
- Ссылка на изображение сохраняется в `profiles.avatar_url`.
- При входе данные профиля, включая `avatar_url`, загружаются из БД.
- Аватар отображается в шапке, профиле, карточках постов и списках чатов; если изображения нет — остаются инициалы.
- Поддерживаются PNG/JPG/WEBP/GIF, размер файла до 2 МБ.
- Добавлены `maxlength` для основных полей форм и проверки на стороне JS.
- Добавлены серверные CHECK-ограничения для текстовых полей. Они применяются к новым/изменяемым данным, старые записи миграция не блокирует.
- Обновлена версия Service Worker, чтобы браузеры забрали новые файлы.

## Обязательная настройка Supabase
1. Открой Supabase → SQL Editor.
2. Выполни `supabase/avatar-and-limits-migration.sql`.
3. Если SQL ругнётся на отсутствие таблицы `user_posts`, сначала выполни `supabase/profile-posts-migration.sql`, затем повтори новую миграцию.
4. Если используешь личные сообщения, выполни обновлённый `supabase/chat.sql`, чтобы функции поиска профилей также возвращали `avatar_url`.
5. После публикации сайта обнови страницу с очисткой кэша. На телефоне при необходимости закрой установленное PWA и открой сайт заново.

## Важно
- В `js/config.js` должен оставаться только Supabase anon/publishable key. Никогда не размещай `service_role` key в клиентском коде.
- Я не могу выполнить SQL в твоём Supabase напрямую из архива: миграцию нужно запустить вручную в SQL Editor.


## Дополнительное исправление: аватары и мобильный поиск
- Аватары в backend-режиме больше не сохраняются в localStorage как запасной вариант при недоступном Supabase.
- Загрузка аватара идёт в публичный bucket `avatars`, ссылка сохраняется в `profiles.avatar_url`; имена файлов уникальные, чтобы избежать кеширования старой картинки.
- При входе старая локальная base64-аватарка автоматически переносится в Supabase Storage, если в профиле ещё нет `avatar_url`.
- После сохранения проверяется, что строка профиля действительно обновлена в БД.
- На телефонах строка поиска вынесена на отдельную строку шапки; выбор результата работает через `click`, а не `mousedown`, поэтому поддерживает touch.
- Обновлена версия Service Worker для сброса старых файлов из кеша.

Для работы аватаров необходимо один раз выполнить `supabase/avatar-and-limits-migration.sql` в Supabase SQL Editor.
