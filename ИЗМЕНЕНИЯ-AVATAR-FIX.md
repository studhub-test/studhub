# StudHub — исправление общих аватарок

## Почему раньше не работало
- В исходной схеме `profiles` не было `avatar_url`.
- `public_profiles`, `chat_find_profiles` и `chat_get_profiles` не возвращали URL аватарки.
- Фронтенд читал `user.avatar` из локального профиля и конвертировал выбранное изображение в Data URL, который не был доступен другим пользователям.

## Что изменено
- Аватар загружается в Supabase Storage, bucket `avatars`, в персональную папку `<user-id>/`.
- В `profiles.avatar_url` сохраняется публичный URL.
- При входе данные профиля, включая `avatar_url`, загружаются из Supabase.
- Публичный профиль, поиск и RPC чата возвращают `avatar_url`.
- Профиль отображает URL из БД; локальное поле больше не является источником общей аватарки.
- Добавлены ограничения типов и размера файла (PNG/JPG/WEBP/GIF, до 2 МБ).

## Обязательный шаг
Выполнить `supabase/avatar-public-profiles-migration.sql` в Supabase → SQL Editor. Без миграции новый код не сможет сохранить и прочитать `avatar_url`.

После этого опубликовать файлы проекта и проверить с двух разных аккаунтов/браузеров. Успех не может быть подтверждён до выполнения миграции в реальном проекте Supabase.
