# StudHub — исправление юзернеймов

## Что исправлено
- Поле юзернейма есть в форме регистрации и корректно переводится на русский/английский.
- Перед регистрацией сайт проверяет, свободен ли юзернейм в таблице `profiles`.
- Если юзернейм занят, показывается сообщение «Этот юзернейм уже занят. Выберите другой.» вместо создания имени из email.
- Обновлена версия Service Worker до `studhub-v7`, чтобы браузер загрузил свежие файлы.

## Установка
1. В GitHub-репозитории замени файлы `index.html`, `js/auth.js`, `js/backend.js`, `js/profile.js`, `js/i18n.js`, `sw.js` файлами из этого архива.
2. Открой Supabase → SQL Editor. Если ты уже запускал старую миграцию юзернеймов, всё равно выполни обновлённый `supabase/username-migration.sql`: в нём добавлена функция проверки доступности имени. Скрипт рассчитан на повторный запуск.
3. Дождись публикации GitHub Pages.
4. Открой сайт, сделай `Ctrl + Shift + R`. Если старая версия всё ещё показывается, закрой вкладку и открой сайт заново.
5. Проверь регистрацию с уже занятым юзернеймом. Должна появиться ошибка «Этот юзернейм уже занят. Выберите другой.»

## Важно
Не удаляй и не очищай таблицы `auth.users`, `profiles` или `wallets`. Если SQL Editor выдаст ошибку, не пытайся обходить её удалением данных — пришли текст ошибки.
