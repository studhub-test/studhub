# StudHub — комментарии, оценки и удаление демо-проектов

## Что меняется
- Комментарии к постам профилей и краудфандинговым проектам сохраняются в Supabase.
- Оценки постов, проектов и обсуждений сохраняются в Supabase отдельно для каждого аккаунта. Один пользователь может поставить `+1`, `-1` или убрать свою оценку.
- Ответы внутри обсуждений продолжают использовать существующую таблицу `discussion_comments`.
- Убраны встроенные пять демо-проектов; главная показывает только реальные проекты.
- В SQL-миграции удаляются записи `projects`, у которых `owner_id IS NULL` (в исходной схеме так были обозначены демо-проекты). Проекты пользователей с владельцем не удаляются.
- Service worker обновлён до `studhub-v9`, чтобы браузер не использовал старый JS.

## Установка
1. Сделай резервную копию репозитория (GitHub → Code → Download ZIP).
2. Скопируй из архива папки `js/` и файл `sw.js` в соответствующие места репозитория, заменив существующие файлы.
3. В Supabase открой **SQL Editor → New query**.
4. Скопируй и выполни целиком `supabase/interactions-and-cleanup.sql`.
5. Дождись публикации GitHub Pages, затем обнови сайт `Ctrl + Shift + R`.

SQL можно запускать повторно: таблицы и политики создаются идемпотентно. Он не удаляет пользовательские посты, комментарии или оценки. Удаляются только проекты с `owner_id IS NULL`, которые исходная схема использовала для демо-проектов.

## Проверка
1. С аккаунта A создай пост, оставь комментарий и поставь оценку.
2. Открой сайт в другом аккаунте/браузере: комментарий и суммарная оценка должны отображаться.
3. Попробуй оценить тот же объект из второго аккаунта; оценка должна сохраняться независимо.
4. Открой обсуждение и проверь, что голос сохраняется после обновления, а ответы по-прежнему работают.
5. На странице сбора средств не должно быть «Карты тихих мест», «Студенческой мастерской», «Учебного бота-помощника», «Доступной 3D-печати» и «Студенческого журнала», если это были демо-записи.

Для комментариев и оценок требуется авторизованный аккаунт. Публично читать комментарии и оценки можно; изменять или удалять чужие оценки/комментарии нельзя.
