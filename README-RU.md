# StudHub — посты в БД и поиск профилей

## Что добавлено
- Публикации сохраняются в Supabase, а не только в localStorage.
- Посты загружаются на любом устройстве после входа в тот же аккаунт.
- Можно искать других пользователей по имени или `@username` через общий поиск StudHub.
- По клику на результат открывается публичный профиль с публикациями и проектами пользователя.
- Редактировать и удалять можно только собственные публикации; чужие профили доступны только для просмотра.
- В `sw.js` обновлён номер кэша до `studhub-v8`.

## Установка
1. Скачайте резервную копию текущего репозитория.
2. Скопируйте файлы из архива в корень проекта, сохранив структуру папок: `index.html`, `sw.js`, `js/` и `supabase/`.
3. Откройте Supabase → SQL Editor → New query.
4. Скопируйте и выполните **только** `supabase/profile-posts-migration.sql`. Не удаляйте таблицы и не запускайте повторно другие миграции без необходимости.
5. Дождитесь публикации GitHub Pages. Откройте сайт и нажмите `Ctrl + Shift + R`.

## Проверка
1. Войдите в аккаунт A и создайте пост в профиле.
2. Обновите страницу: пост должен остаться.
3. Войдите во второй аккаунт или откройте сайт в другом браузере и найдите первый аккаунт по `@username`.
4. Нажмите на результат: должен открыться профиль, а опубликованный пост должен быть виден.

Важно: если в `js/config.js` не настроен Supabase, приложение работает в локальном режиме, и межустройственная синхронизация невозможна.
