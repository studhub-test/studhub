# StudHub — исправление лайков в окне проекта

## Что исправлено
В окне локального проекта ключ голосования имеет формат `uproj-...`, но обработчик поддерживал только `post-`, `proj-` и `disc-`. Поэтому нажатие лайка в окне проекта не попадало в таблицу `content_votes`. Теперь `uproj-` также распознаётся как проект.

## Установка
1. На GitHub замени `js/ratings-comments.js` файлом из этого архива.
2. Замени `sw.js` файлом из архива (версия кэша повышена до `studhub-v10`).
3. Дождись публикации GitHub Pages и обнови сайт `Ctrl + Shift + R`.

SQL повторно запускать не нужно.

## Проверка
Открой проект в личном кабинете, поставь положительную или отрицательную оценку, обнови страницу и проверь сохранение. Для проверки межаккаунтного сохранения открой тот же проект со второго аккаунта.
